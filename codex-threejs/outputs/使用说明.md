# 雨宿り · After the last train

直接双击 `index.html`，用 Edge 或 Chrome 打开。全部依赖已内嵌，可以断网运行，不需要安装软件或启动服务器。网页只有三维场景，不显示操作面板。

- 左键拖拽：旋转；滚轮：缩放；右键拖拽：平移。
- 触屏：单指旋转，双指缩放和平移。
- 自动门每 15 秒开合一次；雨、屋檐滴水、水洼波纹、路面倒影与微弱灯光变化持续运行。

场景使用 Three.js r170 / WebGL 2，通过 JavaScript 生成建筑、真实室内、饮料瓶、货架、关东煮柜、贩卖机、自行车、透明伞、雨伞架、路灯、管线与街道。没有 Blender 文件、预制模型、外部图片或模型加载请求。画布纹理仅用于文字、招牌和商品海报。

采用卡通渐变材质、几何描边、阴影与轻量泛光。路面使用镜像摄像机实时渲染三维场景，再叠加水面扰动和不规则湿润区域。雨线与水洼波纹由 GPU 着色器驱动。窗口尺寸改变时自动适配构图。

本机检查已覆盖：Edge / Intel UHD 硬件 WebGL 2、直接打开本地 HTML 且无网络请求、完整正方形底座、正面/侧面/背面近景、自动门完整周期、鼠标旋转/缩放/平移、横竖窗口适配、不同时间点画面变化、JavaScript 与 WebGL 错误检查。具体检查记录在 `验证记录.json`；帧率为短时测试样本，随窗口尺寸和设备负载变化。

`index.html` 的第二段 `<script>` 是带注释的可编辑场景源代码；第一段为内嵌的 Three.js 与官方附加组件。MIT 许可文本附在 HTML 末尾。

`preview.png` 是本机浏览器实际渲染截图。
